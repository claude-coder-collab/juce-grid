# Keyboard

On macOS, Ctrl in this table means Cmd, except in Ctrl+Tab.

| Key | In the Grid | In a cell editor |
|---|---|---|
| Arrows | Move the cursor | Move the caret |
| Shift+arrows | Extend the selection | Select text |
| Ctrl+arrows | Jump to the first/last row or column | Jump by word |
| Page Up / Page Down | Move by a page | |
| Home / End | First / last column | Start / end of the text |
| Ctrl+Home / Ctrl+End | First / last cell | |
| Tab / Shift+Tab | Next / previous cell, wrapping rows; leave the Grid past either end | Commit, then move |
| Enter / Shift+Enter | Down / up | Commit, then move |
| Ctrl+Tab / Ctrl+Shift+Tab | Leave the Grid | Commit, then leave |
| F2 | Edit, text selected | |
| Any character | Edit, replacing the text | Type |
| Escape | Forget a cut | Cancel the edit |
| Delete / Backspace | Clear the selected cells | Delete text |
| Ctrl+A | Select all | Select all text |
| Ctrl+C / X / V | Copy / cut / paste | Text clipboard |
| Ctrl+Z, Shift+Ctrl+Z or Ctrl+Y | Model undo / redo | Editor undo / redo |
| Ctrl+= (or Ctrl++) | Insert blank rows | |
| Ctrl+− | Delete rows | |
| Shift+F10 | Context menu at the cursor | |

Hidden rows and columns are skipped by every movement. Inside a multi-cell selection, Enter and Tab move through the selected cells only.
